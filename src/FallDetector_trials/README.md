# FallDetector_trials

Arduino sketch for the Waveshare ESP32-S3-Touch-AMOLED-2.06 watch.

- `FallDetector_trials.ino` sampling, display, SD logging and trial buttons
- `fall_detect.c`, `fall_detect.h` impact-triggered window features and random-forest evaluation
- `fall_model.h` trained model, generated by `src/fall_model/export_c.py`

Open the `.ino` in the Arduino IDE (the folder name must match the sketch name). Board and
library settings are listed at the top of the sketch. SD card output is described in
`data/sessions/README.md`.
