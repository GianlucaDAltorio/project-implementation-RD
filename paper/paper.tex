\section{Idea and Outline}
Fall incident detection for at-risk individuals (elderly people or workers in hazardous environments):
\begin{itemize}
    \item ESP32 smartwatch: onboard accelerometer/gyroscope detects fall patterns + triggers alerts.
    \item AI angle: model detects falls vs false positives (high-risk technical question).
    \item IoT angle: notifications are pushed to a caregiver/foreman via an app/dashboard/gateway. 
\end{itemize}

Main idea: detect a fall or accident, report the fall through the system that informs someone is hurt.

\section{Things to Note}
\begin{enumerate}
    \item Fall detection algorithm:\\
        Run a lightweight classifier locally, on the watch.  ESP32 has limited compute/memory.  Important to verify while implementing.  Watch streams IMU data to gateway.
    \item Alert mechanism:\\
        Beyond the watch, we have the receiving dashboard.  Simple web dashboard (e.g. Raspberry Pi running a web server). 
\end{enumerate}
